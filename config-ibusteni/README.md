# [Ibus-Teni](https://github.com/teni-ime/ibus-teni/releases/tag/v1.5.3)

Install and config setup Ibus-teni for Vietnamese
- Download and install
```bash
wget https://github.com/teni-ime/ibus-teni/releases/download/v1.5.3/ibus-teni_1.5.3-0_amd64.deb
sudo apt install ./ibus-teni_1.5.3-0_amd64.deb
```
- Configuration:
+ Open ibus preferences, go to ***Input Method***, add **Vietnamese - Teni**
+ Change keyboard shortcuts to CRTL+Space to switch language
+ On VI setup choose: 
    + Kiểu gõ Telex
    + Dấu thanh chuẩn
    + Giữ nhiều chữ
    + Đúng chính tả
